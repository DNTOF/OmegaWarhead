# 管理员指南

本页面向**服务器管理员/服主**，介绍权限、数据查询与运营建议。

---

## 权限模型

### 无玩家权限要求

OmegaWarhead **不需要任何 EXILED 权限组配置**。游戏内所有玩法对全体玩家开放，不涉及权限系统。

### 管理信息查询（限制访问）

插件提供管理信息查询功能，**仅服务器工作人员可用**：

| 身份 | 是否可用 |
|---|---|
| 服务器控制台（Server Console） | ✅ |
| 全权限管理员（Full Permissions） | ✅ |
| 普通玩家 | ❌ |

普通玩家调用会收到拒绝提示。

---

## 管理数据查询

授权用户可查询以下插件数据：

- **上次更新时间**：插件最近一次更新的时间
- **累计发射次数**：插件运行以来 OMEGA 核弹成功引爆的总次数（跨重启持久化）
- **DLL 校验值**：当前插件文件的 SHA-256 哈希，可用于验证文件完整性

> 💡 用途示例：怀疑 DLL 被篡改时，对比 SHA-256 与 GitHub Release 上的一致即可验证。

### 验证文件完整性

1. 查询当前 DLL 的 SHA-256
2. 到 [GitHub Releases](https://github.com/DNTOF/OmegaWarhead/releases) 下载对应版本
3. 本地计算下载文件的 SHA-256（PowerShell：`Get-FileHash -Algorithm SHA256`）
4. 对比两值是否一致

## 运营建议

### 服务器宣传

- 插件机制适合**滚服宣传**：收集阶段全服追逐、倒计时阶段全服围剿，天然制造节目效果
- 建议服务器开启**回合时间充裕**的配置（268 秒倒计时 + 收集阶段），避免节奏过快

### 平衡性观察

- 留意**元素持有者的存活时间**：如果没人抢元素，收集阶段会非常平静
- 留意**拦截成功率**：如果开核者永远能活到引爆，可以考虑联系作者定制数值（数值硬编码不可配置）
- 观察 **SCP-079 的体验**：原版核弹逻辑直接击杀 079，无需额外处理

### 与第三方插件兼容

- OmegaWarhead 的核弹触发会调用原版核弹逻辑，与其他修改核弹的插件**可能冲突**，建议排查
- 身份重置使用 `Tutorial` 角色，若服务器有特殊角色插件，注意观察兼容性

## 统计与遥测

插件跨重启持久化统计发射次数（见 [配置说明](Configuration) 的数据文件章节）。

> 📡 **预留接口**：未来版本将提供可选的匿名统计上报接口，供服务器主自愿参与。当前版本不收集、不上传任何玩家数据。

---

## 安全建议

1. **不要将 DLL 或配置文件分享给不受信任的人**——修改后可能导致不公平玩法
2. 定期对比 DLL 的 SHA-256 与官方 Release，防止被植入后门
3. 自动更新功能会从 GitHub Releases 下载文件——如服务器无法访问 GitHub，可关闭外网或定期手动更新
