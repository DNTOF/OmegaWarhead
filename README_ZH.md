## 插件简介

OmegaWarhead 将原版的 Alpha 核弹引爆机制替换为一套**多阶段、玩家驱动的发射系统**。玩家不再需要简单地进入核弹井按开关，而是必须：

1. **收集** 散落在设施各处的放射性元素
2. **合成** 集齐足够元素后自动合成核弹发射控制器
3. **确认** 通过两步激活流程确认发射
4. **存活** 在倒计时期间面对整个服务器的追杀

系统包含自定义 UI 面板（基于 HintServiceMeow）、全服位置追踪、CASSIE 播报，以及不可逆的发射机制。

> 💡 **灵感来源**：本插件灵感来自《使命召唤：战区》（Call of Duty: Warzone）中的 **Champions Quest（冠军任务 / 核弹任务）** —— 收集元素、组装装置、确认发射，然后在全大厅的追杀中存活下来。

## 游戏流程

```
┌─────────────┐    ┌──────────────┐    ┌──────────┐    ┌───────────┐    ┌────────────┐
│  收集阶段    │ →  │  自动合成    │ →  │ 双重确认  │ →  │  倒计时   │ →  │  引爆     │
│  (拾荒)     │    │  (合成)      │    │ (两步)   │    │ (存活)    │    │ (全服)     │
└─────────────┘    └──────────────┘    └──────────┘    └───────────┘    └────────────┘
```

### 第一阶段：收集
- **放射性元素**随机刷新在设施内各个房间（默认同时存在 6 个）
- 每持有 1 个元素每秒造成 **1 点伤害**（线性叠加）
- 持有元素会触发**全服位置广播**，方便他人追杀你
- 元素被拾取后，会在**新的随机房间**重新刷新（默认延迟 45 秒）

### 第二阶段：合成
- 集齐所需数量（默认 5 个）后，元素会被**自动消耗**
- 自动合成 **核弹发射控制器** 并放入背包
- 屏幕上出现 HSM 面板，显示待机状态

### 第三阶段：确认
- 按下绑定按键（默认 **K**）启动发射程序
- 进入**确认窗口**（默认 5 秒）——必须在窗口内再次按键确认
- 超时 → 回到待机（可以重试）
- 二次确认 → 你的身份被重置为 **Tutorial**（脱离原阵营）

### 第四阶段：倒计时
- 开始倒计时（默认 268 秒 / 4分28秒）
- 开核者获得生存装备（移速加成、微型 HID、重型护甲、E11-SR）
- 开核者位置以高频广播给全服
- CASSIE 播报关键节点（60秒、30秒、10秒）
- **不可逆点**（默认剩余 10 秒）：越过此点后，开核者死亡也无法中止发射

### 第五阶段：引爆
- 倒计时归零 → 触发原版核弹（击杀 SCP-079 + 视觉效果）
- 短暂延迟后，**击杀所有存活玩家**（全局击杀，覆盖原版核弹炸不到的区域）
- 回合正常结束

## 配置说明

`config.yml` 中只开放以下选项 —— 所有游戏平衡数值都**硬编码进程序集**（`Configs/Constants.cs`），无法通过配置文件修改，确保插件防篡改：

| 选项 | 默认值 | 说明 |
|---|---|---|
| `is_enabled` | `true` | 是否启用插件 |
| `debug` | `false` | 是否输出调试日志 |
| `lang` | `zh` | 插件语言：`zh`（简体中文）或 `en`（英语） |

所有玩家可见文本（面板 UI、追踪广播、物品名称/描述、CASSIE 播报、击杀原因）都会跟随配置的语言。CASSIE 播报现在还会为玩家显示**字幕**。

## 自定义物品

### 放射性元素（ID: 10001）
- 外观为地面上的硬币
- 持有期间持续造成辐射伤害
- 随机刷新在非黑名单房间（排除电梯、地表、检查站等）

### 核弹发射控制器（ID: 10002）
- 外观为混沌分裂者钥匙卡
- 通过自动合成获得（不可拾取刷新）
- **全局限一**：整局游戏只能存在一个
- 若开核者在不可逆点前死亡，控制器销毁

## 自动更新

插件启用时自动检查 GitHub Releases 页面是否有新版本。如果发现新版本，会自动下载新 DLL 并**覆盖当前插件文件**——下次服务器重启或插件重载时生效。更新检查在后台线程运行，绝不会阻塞或崩溃插件。

---

## 统计数据

插件跨重启持久化统计信息，并向授权的服务器工作人员（服务器控制台或全权限管理员）展示。未来版本**预留了遥测/统计上报接口**，允许服务器主自愿选择是否参与匿名使用统计。

## 安装方法

1. 确保服务器已安装 **EXILED** 和 **HintServiceMeow**
2. 从 [Releases](https://github.com/DNTOF/OmegaWarhead/releases) 下载最新的 `OmegaWarhead.dll`
3. 将 DLL 放入服务器的 `EXILED/Plugins` 文件夹
4. 重启服务器（或使用 EXILED 的热重载）
5. 按需修改 `EXILED/Configs/OmegaWarhead/` 下的 `config.yml`

---

## 按键绑定

玩家可以在游戏内 **设置 → 按键绑定** 中自定义确认按键：

- **标签**：`OMEGA核弹发射控制器：确认操作`
- **默认按键**：`K`
- **触发条件**：背包内持有控制器（不需要当前手持）

## 从源码构建

```bash
git clone https://github.com/DNTOF/OmegaWarhead.git
cd OmegaWarhead
dotnet restore
dotnet build -c Release
```

编译产物位于 `bin/Release/OmegaWarhead.dll`。
